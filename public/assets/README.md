# Forever Us media shelf

This is the intentionally obvious local media replacement folder. Drop the couple's
own files here using the names referenced in `src/data.ts`:

- `entry-loop.mp4` and `birthday-surprise.mp4`
- `midnight-in-the-city.mp3`, `orbit.mp3`, `golden-hour-again.mp3`, `the-way-home.mp3`, `signal-through-the-dark.mp3`
- `cover-*.jpg` and `playlist-*.jpg`
- `memory-01.jpg` through `memory-04.jpg`
- `voice-note-01.mp3` and `voice-note-02.mp3`

The interface intentionally renders cinematic color fallbacks if any file is absent,
so the experience remains usable before personal media is added.
